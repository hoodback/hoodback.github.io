# Qué ofrece

1. Almacenamiento en la nube.
   1. Los usuarios guardan llaves de acceso a productos adquiridos.
   2. Los usuarios tienen una nube privada diseñada para utilizarla de forma recurrente. Pueden compartir llaves de acceso para evitar enlaces innecesarios y organizar esos datos sin gastar su nube privada.
   3. Permite alternar entre guardado local y nube para optimizar el uso de la nube.

2. Comercio electrónico.
   1. Los usuarios pueden distribuir productos digitales (ilustraciones, pegatinas, maquetas musicales, archivos de configuración) distribuidos con ventajas respecto a alternativas:

      * Licencia de uso
      * Presentación competitiva de slots (subasta/slot)
      * Interés deducido por volúmen de venta
